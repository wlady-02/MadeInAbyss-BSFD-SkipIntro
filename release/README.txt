MADE IN ABYSS: BINARY STAR FALLING INTO DARKNESS - SKIP INTRO
Version {VERSION} - for the Steam (PC) version, game build 10136809
https://github.com/wlady-02/MadeInAbyss-BSFD-SkipIntro

WHAT IT DOES
The startup screens pass in a moment and the title screen's entrance animation
plays quickly, so the menu is ready about 3 seconds after the game window
appears instead of about 34. Everything else in the game stays the same.

NOTICE
- Unofficial, free fan mod, not affiliated with the developers or publishers.
- Made with the help of an AI (Claude by Anthropic), tested in game by
  wlady-02.

INSTALLATION
1. In Steam: right click on the game -> Manage -> Browse local files.
2. Extract the zip into that folder; it puts
   MadeInAbyss-BSFD-SkipIntro_98_P.pak in MadeInAbyss-BSFD\Content\Paks.
3. Or copy MadeInAbyss-BSFD-SkipIntro_98_P.pak into
   MadeInAbyss-BSFD\Content\Paks by hand.

Works on Windows, Linux (Proton) and Steam Deck (desktop mode).

COMPATIBILITY
- Works with the Italian translation and with UE4SS mods.
- Does not work with other mods that change the startup or title screens.
- Saves and settings are not touched.
- After a game update the mod may stop working: remove it and check for a new
  version.

UNINSTALL
Delete MadeInAbyss-BSFD-SkipIntro_98_P.pak from MadeInAbyss-BSFD\Content\Paks.
Saves are not touched.
